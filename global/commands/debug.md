# /debug

Diagnose only; don't fix.

1. If the session isn't in a worktree, create + enter one per `~/.claude/playbooks/worktree.md`.
2. If test harness exists, write a test reproducing the issue.
3. Add logging at relevant code points.
4. Report findings. Fixing is a separate step.
